# QuickDrag WE

テキスト・URL・画像をドラッグするだけで、検索・タブ開き・画像保存などを素早く実行できるブラウザ拡張機能です。

## インストール

### Firefox

<https://addons.mozilla.org/ja/firefox/addon/quickdrag-we/>

> **重要（Firefox のみ）**  
> インストール後、必ず以下の手順でユーザーデータへのアクセスを有効にしてください。  
> `ツール(T)` → `拡張機能とテーマ` → `QuickDrag WE` → `権限とデータ` タブ →  
> `任意:` の `保存されたすべてのウェブサイトのユーザーデータへのアクセス` をオンにする  
>
> これは Manifest V3 の制限によるもので、オフのままだとアドオンが動作しません。

### Chrome / Edge

<https://chrome.google.com/webstore/detail/quickdrag-for-chrome/dmmpggjbbkfmldkfonjnpbdcmienbjil>

## 使い方

### テキストをドラッグ → 検索

ページ上のテキストを選択してドラッグすると、設定した検索エンジンで検索します。

### URL・リンクをドラッグ → タブで開く

ページ上の URL やリンクをドラッグすると、新しいタブで開きます。

### 画像をドラッグ → 保存またはタブで開く

画像をドラッグすると、設定に応じてダウンロードダイアログを表示するか、新しいタブで開きます。

### 修飾キー

ドラッグ中に以下のキーを押すと動作を切り替えられます。

| キー | ドラッグ対象 | 効果 |
| --- | --- | --- |
| **Shift** | すべて | ブラウザ標準のドラッグ動作にフォールバック（QuickDrag を無効化） |
| **Ctrl** | テキスト（検索） | 検索を実行しつつ、元テキストをクリップボードにコピー |
| **Ctrl** | URL | タブで開きつつ、URL をクリップボードにコピー |
| **Ctrl** | 画像 | ダウンロードダイアログなしでアンカー経由ローカル保存 |
| **Alt** | 画像 | ダウンロードせず、画像 URL を新規タブで開く |
| **Alt**（Ctrl なし） | URL | タブで開かずダウンロード |

## 機能

### 対応 URL フォーマット

ドラッグしたテキストやリンクが以下の形式であれば自動で認識・変換して開きます。

| 形式 | 例 | 動作 |
| --- | --- | --- |
| 通常の URL | `https://example.com` | そのまま開く |
| スキームなし URL | `example.com` | `https://` を補完して開く |
| 難読化 URL | `ttp://example.com`, `hxxps://example.com` | `https://` に正規化して開く |
| メールアドレス | `user@example.com` | `mailto:` リンクとして開く |
| FTP | `ftp.example.com` | `ftp://` として開く |
| 埋め込み画像 | `data:image/...` | Blob URL に変換してタブで開く |

### iframe・frame 内のドラッグ

ページ内の `iframe` や `frame` をまたぐドラッグに対応しています。フレーム間でドラッグ情報を同期するため、埋め込みコンテンツ上でも正しく動作します。

### SPA（シングルページアプリ）対応

React・Vue・Angular などのフレームワークを使ったサイトでも、URL が変わるたびにサイトルールを再チェックします。

### サイトルール

特定のサイトで QuickDrag WE を無効化（または有効化）できます。

#### 現在のサイトを無効化する

オプションページ上部のトグルで、現在表示中のサイトを簡単に無効化/有効化できます。

#### ルール一覧を編集する

`サイトルール` のリンクをクリックすると、ルールを一覧で管理できます。

| 種類 | 形式 | 例 | 説明 |
| --- | --- | --- | --- |
| ホスト名 | `ホスト名` | `example.com` | そのホスト名のみに一致 |
| 正規表現 | `/パターン/` | `/example\.(com\|net)/` | 正規表現で URL をマッチ |

各ルールは「無効化」または「有効化」の状態を持ちます。有効化ルールは無効化ルールより優先されるため、特定ページだけを例外的に有効にすることもできます。現在開いているタブの URL に一致するルールはハイライト表示されます。

## 設定

拡張機能のアイコンをクリック、またはオプションページから設定を変更できます。

### 検索エンジン

| エンジン | 備考 |
| --- | --- |
| Google | デフォルト |
| Google USA | パーソナライズなし・米国ロケール |
| Bing | |
| Baidu | |
| Yandex / Yandex RU | |
| Yahoo / Yahoo Japan | |
| Naver | |
| DuckDuckGo | |
| 360搜索 | |
| Ask | |
| **Custom** | 任意の URL を指定 |

`%s` を含めるとドラッグした文字列がその位置に埋め込まれます（含めない場合は末尾に追加されます）。

### 新しいタブを開く位置

| 設定値 | 動作 |
| --- | --- |
| **右（デフォルト）** | 現在のタブの右隣に開く |
| 左 | 現在のタブの左隣に開く |
| 最後 | タブバーの一番右に開く |
| 最初 | タブバーの一番左に開く |

### トグルスイッチ

| 設定 | デフォルト | 説明 |
| --- | --- | --- |
| **URL をフォアグラウンドで開く** | オン | URL ドラッグ時、開いたタブをすぐアクティブにする |
| **検索をフォアグラウンドで開く** | オン | テキスト検索時、開いたタブをすぐアクティブにする |
| **画像をドラッグで保存する** | オン | 画像ドラッグ時にダウンロードダイアログを表示する |
| **リンク付き画像では保存を優先する** | オン | `<a>` で囲まれた画像をドラッグしても、リンク先へ移動せず画像保存を優先する |

## よくある質問

**Q: ドラッグしても何も起きない**  
A: Firefox の場合、`保存されたすべてのウェブサイトのユーザーデータへのアクセス` がオンになっているか確認してください（[インストール](#インストール)参照）。

**Q: 特定のサイトだけ無効にしたい**  
A: オプションページのトグルか、サイトルールを使って無効化できます（[機能 > サイトルール](#サイトルール)参照）。

**Q: 画像ドラッグで保存ではなく開きたい**  
A: 設定の「画像をドラッグで保存する」をオフにしてください。

**Q: 検索結果をバックグラウンドで開きたい**  
A: 設定の「検索をフォアグラウンドで開く」をオフにするか、ドラッグ中に **Ctrl** キーを押してください。
