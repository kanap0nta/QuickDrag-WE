# QuickDrag-WE

QuickDrag Webextensions対応版

インストール先

＜Firefox＞  
<https://addons.mozilla.org/ja/firefox/addon/quickdrag-we/>

`ツール(T)` → `拡張機能とテーマ` → `QuickDrag WE` → `権限とデータ`タブ → `任意:` の項目にある `保存されたすべてのウェブサイトのユーザーデータへのアクセス` のトグルスイッチをオンにしてください。  
Manifest Version 3 の制限により必須の作業となりました。オフの場合、本アドオンが動作しません。

＜Chrome、Edge＞  
<https://chrome.google.com/webstore/detail/quickdrag-for-chrome/dmmpggjbbkfmldkfonjnpbdcmienbjil>
